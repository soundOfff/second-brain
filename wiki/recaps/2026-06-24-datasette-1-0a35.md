# Recap — datasette 1.0a35

Short blog post by [[entities/simon-willison]] announcing the release of
**[[entities/datasette|Datasette]] 1.0a35**, which he calls "a big release," with a
promise to write more the following day
[2026-06-24-datasette-1-0a35]. He highlights three changes from the release notes
[2026-06-24-datasette-1-0a35].

First, a new "Create table" interface in the database actions menu, backed by a
`/<database>/-/create` JSON API, supporting columns, primary keys, custom column types,
`NOT NULL` constraints, literal and expression defaults, and single-column foreign keys
[2026-06-24-datasette-1-0a35]. Second, a new "Alter table" action and
`/<database>/<table>/-/alter` JSON API for modifying existing tables — adding,
renaming, reordering, and dropping columns; changing types, defaults, `NOT NULL`,
primary keys, and foreign keys; renaming the table; and dropping it entirely
[2026-06-24-datasette-1-0a35]. Third, new "Template context" documentation listing the
variables available to custom templates on Datasette's core pages, treated as a stable
API until Datasette 2.0 and generated from dataclass definitions with tests that check
documented fields against actual rendered contexts [2026-06-24-datasette-1-0a35].
Willison also links a short video demo of the new create/alter table feature that he
made while reviewing the underlying PR [2026-06-24-datasette-1-0a35].

## Key claims

- Datasette 1.0a35 adds a "Create table" UI and JSON API (`/<database>/-/create`) supporting columns, primary keys, types, `NOT NULL`, defaults (literal and expression), and single-column foreign keys [2026-06-24-datasette-1-0a35].
- Datasette 1.0a35 adds an "Alter table" UI and JSON API (`/<database>/<table>/-/alter`) for add/rename/reorder/drop columns, changing constraints/types/keys, renaming, and dropping the table [2026-06-24-datasette-1-0a35].
- Datasette 1.0a35 adds "Template context" documentation, generated from dataclasses and tested against actual rendered page contexts, treated as a stable API surface until 2.0 [2026-06-24-datasette-1-0a35].
